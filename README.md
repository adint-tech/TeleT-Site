# TeleT LLC — Website

A single-page static site. No build step, no dependencies — upload the files and it runs.

```
index.html                     the entire site (HTML + CSS + JS)
assets/telet-logo.png          primary lockup (dark wordmark, for light backgrounds)
assets/telet-logo-reverse.png  reverse lockup (light, for dark backgrounds)
assets/telet-mark.png          icon only, 512×512
assets/apple-touch-icon.png    iOS home-screen icon, 180×180
assets/favicon-32.png          browser tab icon
robots.txt                     search-engine directives
sitemap.xml                    single-page sitemap
```

## Before launch — two things to fill in

**1. The domain.** `index.html` uses `https://teletllc.com/` as a placeholder in the
canonical link, Open Graph tags, and structured data. Find and replace it with the real
domain. Do the same in `robots.txt` and `sitemap.xml`. Search engines and link previews need absolute
URLs, so this can't be left relative.

**2. Where the contact form sends.** Near the top of the `<script>` block at the bottom
of `index.html`:

```js
var FORM_ENDPOINT = '';
var CONTACT_EMAIL = 'alitabinda2026@gmail.com';
```

Left empty, the form validates the input and then opens the visitor's own email app with
everything pre-filled and addressed to `CONTACT_EMAIL`. That works everywhere with no
backend, but it depends on the visitor having a mail client set up.

To collect submissions properly instead, sign up for a form service (Formspree, Basin,
Netlify Forms, or similar), paste the POST URL into `FORM_ENDPOINT`, and the form will
submit in the background and show a confirmation without leaving the page:

```js
var FORM_ENDPOINT = 'https://formspree.io/f/xxxxxxxx';
```

The form posts JSON with the keys `name`, `email`, `organization`, `topic`, `message`.

## Deploying

Any static host works — Netlify, Vercel, Cloudflare Pages, GitHub Pages, or plain
shared hosting. Drag the folder in, or point the host at this directory. Serve
`index.html` at the root.

Serve over HTTPS. The site loads fonts from Google Fonts over HTTPS, and mixed content
would be blocked.

## Previewing locally

Opening `index.html` by double-clicking works, but some browsers restrict local files.
Running a small server is more reliable:

```bash
python3 -m http.server 4321
```

Then visit `http://localhost:4321`.

## Editing content

Everything is in `index.html`, in reading order, with commented section markers
(`═══ HERO ═══`, `═══ SERVICES ═══`, and so on). Text lives in the HTML; nothing is
generated by JavaScript except the copyright year.

Colors are defined once as CSS custom properties in the `:root` block at the top of the
`<style>` tag. They are sampled from the logo — navy `#0B2450` from the wordmark, blue
`#2A6FB5` and teal `#109C9C` from the icon — so changing a value there updates the whole
site consistently.

## Notes

- Responsive from 320px up; the navigation collapses to a menu below 940px.
- Accessible: keyboard navigable, labelled form fields with inline validation, skip
  link, and text contrast meeting WCAG 2.1 AA.
- Respects `prefers-reduced-motion` — animations are disabled for visitors who ask for
  that in their OS settings.
- Includes a print stylesheet, so the page prints cleanly to PDF.
- The contact form carries a hidden honeypot field to absorb bot spam.
- The three PNGs in the project root (`telet-logo.png`, `telet-logo-transparent.png`,
  `no backroudn logo.png`) are the original source files. The site does not use them —
  it uses the cropped and optimized copies in `assets/`. They can be archived somewhere
  outside the deploy folder.
