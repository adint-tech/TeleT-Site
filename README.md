# TeleT LLC — Website

A single-page static site. No build step, no dependencies — upload the files and it runs.

```
index.html                     the entire site (HTML + CSS + JS)
assets/telet-logo.png          primary lockup (dark wordmark, for light backgrounds)
assets/telet-logo-reverse.png  reverse lockup (light, for the navy hero and footer)
assets/telet-mark.png          icon only, 512×512
assets/og-image.png            1200×630 link-preview image (Open Graph / Twitter)
assets/apple-touch-icon.png    iOS home-screen icon, 180×180
assets/favicon-32.png          browser tab icon, 32×32
assets/favicon-96.png          browser tab icon, 96×96
robots.txt                     search-engine directives
sitemap.xml                    single-page sitemap
```

## Before launch — two things to fill in

**1. The domain.** `index.html`, `robots.txt`, and `sitemap.xml` use `https://teletllc.com/`
as a placeholder in the canonical link, Open Graph tags, and structured data. Once the real
domain is confirmed, replace the origin in one pass (no trailing slash; the asset URLs
continue from it):

```bash
perl -pi -e 's{https://teletllc\.com}{https://www.REAL-DOMAIN.com}g' index.html robots.txt sitemap.xml
```

Then `grep -rn teletllc.com index.html robots.txt sitemap.xml` must return nothing.
Search engines and link previews need absolute URLs, so this can't be left relative.

**2. Where the contact form sends.** Near the top of the `<script>` block at the bottom
of `index.html`:

```js
var FORM_ENDPOINT = '';
var CONTACT_EMAIL = 'alitabinda2026@gmail.com';
```

Left empty, the form validates the input and then opens the visitor's own email app with
the message pre-filled and addressed to `CONTACT_EMAIL`. The status line under the form
says exactly that and offers a direct link, so nothing is ever reported as "sent" when it
was not. This works everywhere with no backend, but it depends on the visitor having a
mail client set up.

To collect submissions properly, sign up for a form service (Formspree, Basin, Netlify
Forms, or similar), paste the POST URL into `FORM_ENDPOINT`, and the form will submit in
the background and show a confirmation without leaving the page:

```js
var FORM_ENDPOINT = 'https://formspree.io/f/xxxxxxxx';
```

The form posts JSON with the keys `name`, `email`, `organization`, `topic`, `message`.
The hidden spam-trap field is only enforced once an endpoint is configured.

Also update `<lastmod>` in `sitemap.xml` (YYYY-MM-DD) whenever the page content changes.

## Deploying

Any static host works — Netlify, Vercel, Cloudflare Pages, GitHub Pages, or plain
shared hosting. Upload `index.html`, `assets/`, `robots.txt`, and `sitemap.xml`; serve
`index.html` at the root. Serve over HTTPS — the site loads fonts from Google Fonts over
HTTPS, and mixed content would be blocked.

After the first deploy, paste the live URL into LinkedIn's Post Inspector once so the
link-preview cache picks up `assets/og-image.png`.

## Previewing locally

Opening `index.html` by double-clicking works, but some browsers restrict local files.
Running a small server is more reliable:

```bash
python3 -m http.server 4321
```

Then visit `http://localhost:4321`.

## Editing content

Everything is in `index.html`, in reading order, with plain comment markers
(`<!-- Hero -->`, `<!-- Services -->`, and so on). Text lives in the HTML; nothing is
generated by JavaScript except the copyright year.

Colors are defined once as CSS custom properties in the `:root` block at the top of the
`<style>` tag. Navy `#0B2450`, blue `#2A6FB5`, and teal `#109C9C` are sampled from the
logo; the page sits on warm paper (`#FAF8F4`, with `#F2EFE9` for the Approach band).
Headings are Source Serif 4; everything else is Inter. Both load from Google Fonts.

To add a portrait of Tabinda, save it as `assets/tabinda-ali.jpg` (about 800×1000) and
uncomment the `<figure class="portrait">` block in the About section.

## Notes

- Responsive from 320px up; the navigation collapses to a Menu button below 900px.
- Accessible: keyboard navigable, labelled form fields with inline validation, skip
  link, and text contrast meeting WCAG 2.1 AA.
- No scroll animation. The only motion is native anchor smooth-scroll, disabled under
  `prefers-reduced-motion`.
- Includes a print stylesheet, so the page prints cleanly to PDF.
- The three PNGs in the project root (`telet-logo.png`, `telet-logo-transparent.png`,
  `no backroudn logo.png`) are the original source files. The site does not use them —
  it uses the cropped and optimized copies in `assets/`. They can be moved somewhere
  outside the deploy folder.
